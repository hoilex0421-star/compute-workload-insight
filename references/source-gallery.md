# 可分享示例索引

此索引只指向可随skill分发的原创示例，不收录内部原稿、截图、文件路径或原稿回看入口。示例用于学习图文论证与变量交付，不是模型、厂商或硬件性能的事实库。普通非保密资料仍可按当前任务已有授权引用；用户明确保密时遵循 [原创替代规则](visual-style.md#保密素材的原创替代)。

## 三页原创图文示例

[prelude-examples.html](../assets/prelude-examples.html) 包含三张16:9阅读页，使用独立设计的SVG示意图及HTML分析文字。可离线阅读、翻页和放大图示，无内部原图、嵌入扫描图片或原稿整页回看。

可单独编辑的矢量资源存于 [diagrams](../assets/diagrams/)：动作生成、分频协同、在线预测、训练辅助、抽象场景、生成循环、输出对齐，以及迭代、缓存和异步三类优化机制。图形只作原理说明，方块数、时序长度和曲线形态没有实际量纲。

| 示例 | 预览 | 论证任务 | 后续交付 |
|---|---|---|---|
| P2 技术路线比较 | [路线比较](../assets/prelude-example-01.png) | 用原创路线关系图比较模型角色、调用链和状态 | 路线条件、阶段与调用方式 |
| P3 执行机制 | [执行机制](../assets/prelude-example-02.png) | 用原创输入输出与循环示意解释数据形态、重复计算和阶段边界 | 调用次数、单次成本、输入输出及驻留状态 |
| P6 优化与瓶颈 | [优化机制](../assets/prelude-example-03.png) | 用原创机制对照解释成本减少、额外开销和重叠 | 优化工况、变量方向、待测交叉点 |

示例以通用具身智能机制为背景，所有图形均为解释性示意，非实测结果或特定产品实现。符号公式用于展示分解方式，不填入内部配置或未验证性能值。学习重点是主图如何解释判断、分析标注如何连接到变量和条件；不要求后续任务固定制作三页、复制同样布局或采用固定图片占比。

## 与页型目录的关系

A—E负责汇总或建模，P1—P6按缺失论证展开。示例仅覆盖P2、P3、P6，其余页型依据 [页型目录](page-types.md) 与 [前置推导页规范](prelude-pages.md) 选择，不需要内部原图才能使用。

| 页型 | 分工 | 可独立构思的主视觉 |
|---|---|---|
| A 研究工作流 | 谁在何阶段交付什么 | 职责泳道与交付路径 |
| B 全景路线矩阵 | 跨方向比较技术位置与成熟度 | 同维度路线矩阵 |
| C 标准专题洞察 | 连接趋势、机制与系统需求 | 机制证据块、变量趋势与需求表 |
| D 定量建模 | 给定工况下代入并计算 | 阶段工作量、容量、通信或关键路径模型 |
| E Agent系统专题 | 分析多种系统资源共同作用 | 状态驻留、工具调用、缓存与调度关系 |
| P1 场景约束 | 解释系统指标从何而来 | 原创任务场景与约束标注，或获准使用的实图 |
| P2 路线比较 | 解释相同任务的机制差异 | 原创结构关系对照 |
| P3 执行机制 | 解释计算如何发生与重复 | 输入输出示意、阶段流程与循环 |
| P4 变量证据 | 解释基线和情景输入依据 | 有来源的数据图；无数据时用符号变量表 |
| P5 部署分工 | 解释计算位置、状态及链路 | 通用部署泳道与数据流 |
| P6 优化变化 | 解释收益、代价与瓶颈条件 | 机制对照、成本转移与调度时间关系 |

可沿用“场景—路线—机制—变量—负载—系统”的因果链。每个新专题仍需重新确定资料许可范围、事实状态、变量口径与适用条件，不能把示例当成默认事实或内部方案。
